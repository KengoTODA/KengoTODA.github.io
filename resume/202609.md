## 職務概要

フリーソフトウェア開発からキャリアを始め、2018 年以降は大規模 ERP とクラウドネイティブ医療 SaaS の開発・運用・組織マネジメントに従事。Java・Kotlin を中心とするバックエンド開発、JVM・RDBMS・静的解析、SRE、Developer Productivity、情報セキュリティを専門とする。

株式会社ヘンリーでは SRE チームを立ち上げた後、2025年1月に執行役員に就任。20名超のチームを含む開発組織の再設計と権限委譲を10か月で進め、経営者が開発チームの直接マネジメントから離れ、経営上の意思決定へ集中できる体制を構築した。また国が主催する協議会のメンバーとして技術者観点から省庁や業界事業者との議論や調整を担当した。

個人の技術活動では、Rust 製 JVM バイトコード静的解析 CLI を Agentic Coding 中心で開発。仕様、テスト、ベンチマーク、可観測性、リリース承認からなる開発プロセスを設計し、AI による実装速度と品質・性能・説明責任を両立している。

## 主な強み

- **技術と事業を接続する執行**: 技術戦略を、組織設計、投資判断、セキュリティ統制、顧客への価値提供まで落とし込む。
- **組織のスケーリング**: チーム境界、責任、意思決定権を設計し、マネジメント層への段階的な権限委譲を実行する。
- **Developer Productivity / SRE**: CI/CD、ビルド高速化、モノレポ、オブザーバビリティ、クラウドコスト、運用設計を横断して改善する。
- **Agentic Codingと品質保証**: Coding Agentが自律的に完了条件を検証できる仕様、テスト、静的解析、計測、リリース工程を設計する。
- **規制産業のプロダクト設計**: 医療情報、個人情報保護、サイバーセキュリティを製品・契約・運用の一体的な課題として扱う。

## OSS・個人開発

### inspequte — Agentic Coding 向け JVM バイトコード静的解析CLI（2026年〜）

- Rust で Java/Kotlin の class ファイルを解析し、control flow graph、data flow、並列解析、SARIF 2.1.0、GitHub Code Scanning、Gradle 連携を実装。
- 仕様、テストハーネス、ベンチマーク、OpenTelemetry、スモークテストを先に整え、Coding Agent が実装と改善を自律的に進められる Definition of Done を構築。
- 公開後2週間で6回のマイナーリリースを実施。計測結果をもとに並列化と不要なデータ複製の削減を進め、特定処理を約2倍高速化。
- 人間は仕様、偽陽性・偽陰性のテスト、リリース内容と承認に集中する開発フローを実現。
- 詳細: [Agentic Coding用classファイル静的解析ツールをAgentic Codingで実装した](https://blog.kengo-toda.jp/entry/static-analysis-for-agentic-coding)
